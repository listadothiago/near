# Near — backlink / PR outreach log

Durable relationship memory for `.claude/skills/backlink-pr/SKILL.md`.
One entry per target site or contact.

**This file was missing until 2026-09-02.** `backlink-pr` has been a
"mandatory consultation" in `near-seo` and `near-write-article` while the
log it claims to own did not exist — so no outreach was ever recorded,
and most likely none was ever done. Treat the pipeline as starting from
zero rather than assuming prior relationships exist.

**Read this before any outreach.** The point of the log is that a future
session does not re-approach someone mid-conversation, or pitch a site
that already said no.

Record for each: site, the topic/market it outranks Near on, contact
channel found (and how), the date of **every** touch, current state, and
what was pitched. States: `prospect` / `contacted` / `relationship` /
`declined` / `refused-by-us` — the last always with the reason.

**No email is ever sent without showing the operator the exact draft and
getting explicit approval.**
