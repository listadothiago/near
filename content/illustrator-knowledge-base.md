# Illustrator reference library

Operator direction, 2026-09-08: editorial art may be abstract, artistic,
humorous or vector-derived, for heroes and in-body images alike. It need not
depict a venue. Use this compact library to choose an original concept quickly;
do not research a new artist list for every article.

These are visual-culture study references, not instructions to reproduce an
artist's signature style or permissions to reuse their artwork.

## How to use the library

Additional operator references:

- **Laerte:** explore visual metaphor, everyday absurdity and an unexpected
  conceptual turn, using original compositions and broad traits.
- **Glauco:** explore economical cartoon forms, expressive gesture and compact
  comic timing for original in-body vignettes.
- **Angeli:** explore urban satire, unruly nightlife and textured comic energy,
  using broad traits rather than signature characters or exact imitation.

The initial library is now sufficient. Existing assistant additions (Steinberg,
Harper, Blair, Corita Kent and Ungerer) provide conceptual, geometric and collage
alternatives. No further reference hunt is needed before producing articles.

- **Ota (Otacílio Costa d'Assunção Barros):** economical cartoon line,
  irreverent Brazilian magazine humor and caricature. Useful for comic asides
  and original city-life satire. [Publisher biography](https://www.taieditora.com.br/artistas/ota-assuncao).
- **Hajime Sorayama:** the operator's chrome lady-robot reference. Explore
  metallic highlights, machine/body contrasts and retrofuturist glamour as
  broad traits for original, visibly illustrated compositions, without copying
  signature figures. [Official biography](https://www.sorayama.net/artist_bio/artist_bio).
- **Henri de Toulouse-Lautrec:** bold poster composition, expressive contour,
  limited color and theatrical nightlife framing. Useful for original music,
  cabaret and bar illustrations that read immediately at card size.

- Start with the article's specific idea, then choose visual traits that explain
  it. Example: a ramen bowl with a looping extra portion of noodles can explain
  kaedama without pretending to show the restaurant.
- For living artists, translate a reference into broad traits; do not request
  an exact style imitation. Never imply collaboration or artist attribution.
- Create original compositions. Reference artworks are not licensed assets.
- Read at card size: one clear idea, legible silhouette, usable crop. Avoid
  decorative text that adds no meaning.
- Preserve source-photo and other existing fallback priorities; choose an
  illustration when it earns its place. Keep the search bounded.
- Add a reference only when it supplies a useful distinction, preferably after
  a real article demonstrates it. Record the decision once, then reuse it.
