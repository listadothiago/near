# near-editor-party

The general nightlife/party-culture advisor lens for `near-editor` —
this **is** the "insider-tastemaker lens" the main style guide already
names for `nightlife-sound` ("Categories, tags, and 'advisor lenses'").
This skill exists to give that lens its own reference doc as Near's
nightlife coverage has grown (block parties, party series/collectives,
recurring theme nights, a scene spanning multiple venues), rather than
leaving it as a single paragraph in the style guide.

## Relationship to `near-editor-stefon`

**Use this lens by default for nightlife-sound coverage.**
`near-editor-stefon` is a much narrower, deliberately rare tool — only
for the small number of places where the actual sourced details are so
dense and specific that a stacked-list format is more honest than normal
prose (see that skill's own "use sparingly" section). If a candidate
doesn't clear Stefon's bar, this lens is almost always the right one to
reach for instead — most nightlife content should be well-written normal
prose with real insider specificity, not the Stefon format.

## The core discipline: who's actually there, and when it's actually good

- **Real specific color**: a resident DJ or promoter by name, a door
  policy, the hour a night actually gets good, a recurring theme
  night's actual format — not generic "vibrant nightlife" copy.
- **Scenes, not just venues.** A party series or collective that moves
  between venues, a recurring theme night, a block party or street
  festival — these are legitimate subjects in their own right, not just
  venue write-ups. `near-blogger`/`near-war-room` content around a
  scene (a city's house-music clubs, a block-party circuit) should lean
  on this lens for the same specificity discipline.
- **Cover charge, dress code, age/ID realities** — practical door
  information a reader needs, when a source has it.

## LGBTQIA+ nightlife specificity

Per the operator's standing interest: name gay bars, queer parties, and
bear-scene ("ursos") spots specifically and by name when sourced, rather
than a generic "LGBTQ-friendly" aside — this is exactly the kind of
concrete detail this lens exists to insist on. Consult
`near-editor-stefon` too if a specific queer venue's details are dense
enough to earn that narrower treatment, but don't assume LGBTQIA+
coverage automatically means the Stefon register — most of it should
still be this lens's normal insider-tastemaker prose.

## Honesty about fabricated crowds

Same non-negotiable rule already in the main style guide: never invent
who was there, a celebrity sighting, or an imagined crowd. If the source
doesn't name it, Near doesn't claim it — this matters more in nightlife
coverage than almost anywhere else in Near, since the temptation to
imply glamour without a real source is highest here.
