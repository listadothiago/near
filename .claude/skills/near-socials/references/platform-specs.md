# Platform quick reference

| Platform | Hard limits | Format notes |
|---|---|---|
| X/Twitter | 280 chars/tweet | Link + 1–2 hashtags max; images help but aren't drafted here, only the hero image is referenced |
| Threads | 500 chars | More casual than X; no strict hashtag culture, skip them or use 1 |
| Instagram | 2,200 char caption cap (first ~125 chars shown before "more") | Front-load the hook; hashtag block at the end, 5–15 tags, mix broad + specific |
| TikTok | 2,200 char caption cap | Script is for filming, not the caption — caption should be short and punchy |
| YouTube Shorts | Title ~100 chars (aim shorter, ~60), description 5,000 chars (aim for 2–3 sentences) | Title should work standalone in a feed with no other context |

These are platform ceilings, not targets — near-socials should write well
under them by default (see SKILL.md step 3 for actual target lengths).
